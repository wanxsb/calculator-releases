隐私政策 · 计算器小C

生效日期：2026 年 10 月 15 日
适用产品：计算器（Android 版、iOS 版、微信小程序「计算器小C」）

我们不收集你的任何信息。没有账号、没有登录、没有广告、没有统计埋点， 所有计算都在你的设备上完成。

一、我们不收集什么

本应用不收集、不存储、不上传任何个人信息，包括但不限于：

  • 姓名、邮箱、电话、地址等身份信息
  • 设备标识符（IMEI、MAC 地址、广告标识符等）
  • 位置信息
  • 通讯录、相册、麦克风、摄像头等任何设备权限对应的数据
  • 使用行为与统计（没有接入任何统计 SDK）

应用内没有账号体系，因此也不存在注册、登录或绑定手机号。

二、计算过程

所有运算完全在你的设备本地完成，不发送到任何服务器。你输入的数字与算式不会被记录、上传或用于任何其他用途。

三、历史记录

计算历史保存在你设备本地（Android / iOS 使用系统提供的本地存储，微信小程序使用微信提供的本地缓存）。

  • 这些数据不会离开你的设备
  • 你可以随时在应用内清空全部历史
  • 卸载应用即随之删除

四、唯一的一次联网：检查更新（仅 Android / iOS）

应用启动时会向 GitHub 读取一份公开的版本清单文件，用来判断是否有新版本。

  • 这是一次普通的文件读取请求，不携带任何用户数据、设备标识或统计信息
  • 请求内容中不含能识别你个人身份的信息
  • 读取失败（断网、超时等）时静默忽略，不会干扰你使用，也不会弹任何错误

⚠️ 需要如实说明的一点：与所有网络请求一样，托管方 GitHub 会看到发起请求的 IP 地址。 这是互联网通信的固有性质，我们无法控制 GitHub 的日志行为。 详见 GitHub 隐私声明。

若你希望完全不联网，可在系统设置中禁止本应用联网 —— 不影响任何计算功能。

五、微信小程序

微信小程序端不发起任何网络请求（不含检查更新功能）。 你的计算历史存放在微信提供的本地缓存中，可通过小程序内的清空功能删除。

小程序在微信内运行，微信自身的数据处理行为适用 微信隐私保护指引。

六、第三方共享

我们不与任何第三方共享、出售或转让你的信息 —— 因为我们根本没有收集。

七、儿童隐私

本应用不收集任何信息，因此也不会收集儿童的个人信息，适合所有年龄段使用。

八、政策变更

若本政策有变更，我们会更新本文档顶部的「生效日期」。由于我们不收集任何信息，预期不会发生实质性变更。

九、联系我们

如对本政策有疑问，请联系：wanxsb@gmail.com

Privacy Policy

Effective date: October 15, 2026
Applies to: Calculator (Android, iOS, WeChat Mini Program)

We do not collect any of your information. No account, no sign-in, no ads, no analytics. All calculations happen on your device.

What we do not collect

We do not collect, store, or transmit any personal information — no identity information, no device identifiers, no location, no device permissions, and no usage analytics. There is no account system.

Calculation

All computation is performed locally on your device. What you type is never recorded or uploaded.

History

Calculation history is stored locally on your device (or in WeChat's local storage for the Mini Program). It never leaves your device, and you can clear it at any time from within the app.

The one network request: update check (Android / iOS only)

On launch, the app reads a public version manifest file from GitHub to determine whether a newer version exists. This request carries no user data, no device identifiers, and no analytics.

As with any network request, the host (GitHub) will see the originating IP address; we do not control GitHub's logging. See the GitHub Privacy Statement.

The WeChat Mini Program makes no network requests at all.

Third parties

We do not share, sell, or transfer your information to anyone — we do not collect it in the first place.

Children's privacy

We collect no information, so we collect no information from children.
